01 / METHOD

A closed loop between database structure and quantum search.

QDBO keeps the optimization objective visible while iteratively adapting the quantum problem representation.

01

Formulate

Translate join-order or index-selection decisions into a QUBO representation.

02

Map

Place logical variables on available quantum hardware using explicit embedding strategies.

03

Solve

Sample solutions through D-Wave Leap and evaluate them against the database objective.

04

Refine

Feed solution quality back into the next iteration instead of treating the QPU as a black box.

02 / USE CASES

One core, two database optimizers.

Q²O-QDBOJOIN ORDERING

Search better join plans.

Run QDBO across JOB, CEB, and synthetic join graphs, with cost-model evaluation and optional PostgreSQL execution using pg_hint_plan.

  • JOB and CEB workload inputs
  • NL, CQM, BQM, and iterative solver paths
  • Optional real execution measurements

IS-QDBOINDEX SELECTION

Select indexes under budget.

Build and solve a budget-constrained index-selection QUBO over the paper's strict no-primary-key TPC-H setup.

  • Tracked immutable paper inputs
  • Classical, hybrid, and iterative solvers
  • Replay and aggregate-table pipeline
